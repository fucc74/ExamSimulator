# ExamSimulator

An exam-agnostic practice engine that runs as a **single HTML file** (works by double-clicking `exam.html`, no server needed).
Add as many exams as you like: each exam is one `NAME.exam` file.

## Using it
- Open `exam.html`, pick an exam from the list (or open `exam.html?content=NAME`, or `exam.html?url=https://…/NAME.exam`).
- **Modes:** exam-defined modes (e.g. official simulation), full bank, per topic, spaced-repetition review, my mistakes, flagged, unseen, by difficulty.
- **Study mode** (check each answer + explanation) or **exam mode** (change answers freely, review screen before submitting).
- **Timers:** total, per question, or none.
- **Flag & notes** per question; statistics (history, accuracy by topic, hardest questions); export/import of all progress.
- **Keyboard:** `1–6`/`A–F` select, `←/→` move, `Enter` check/next, `M` flag.
- English/Italian UI toggle, light/dark theme, installable and usable offline (when served over http/https).

## Adding an exam
1. Create `NAME.exam` (format 2 — see [docs/EXAM-FORMAT.md](docs/EXAM-FORMAT.md)).
2. `node tools/validate-exam.js NAME.exam` — readable errors and quality hints.
3. `npm run build` — regenerates the exam list, `exam.html` and the offline cache list.

Old-style exam files (`window.ExamData = {config, questions}`) still load; convert them with `node tools/convert-legacy.js`.

## Development
```
src/            sources (styles, js modules, template)
tools/          build.js, make-manifest.js, validate-exam.js, convert-legacy.js
tests/          unit tests (node:test) and browser end-to-end tests (Playwright)
exam.html       GENERATED single-file build — do not edit by hand
exams.js, sw.js GENERATED by `npm run build`
```
- `npm run build` — bundle `src/` into `exam.html`
- `npm test` — unit tests (no dependencies)
- `npm run e2e` — browser tests (needs Playwright + Chromium; `NODE_PATH=$(npm root -g) node tests/e2e.js`)

Extension points are described in [docs/API.md](docs/API.md) (events, custom question types and modes).
